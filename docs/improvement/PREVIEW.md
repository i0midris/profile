# معاينة الشكل النهائي للموقع

لرؤية الموقع وكل أقسامه ممتلئة بمحتوى تقريبي: المنتجات، والمدونة، ودراسات الحالة، والأسئلة الشائعة، والفريق، وآراء العملاء، والخريطة. **على جهاز التطوير فقط.**

## التشغيل

```bash
git fetch origin
git checkout abdalsalam
composer install
npm install
cp .env.example .env          # إن لم يكن موجوداً
php artisan key:generate      # مرة واحدة
php artisan migrate
php artisan storage:link
php artisan preview:content   # يضيف المحتوى التقريبي
php artisan serve             # ثم في نافذة أخرى: npm run dev
```

افتح `http://localhost:8000/ar`.

## الإزالة

```bash
php artisan preview:content --remove
```

يحذف كل ما أضافه بالضبط (27 عنصراً و24 صورة)، ويعيد إعدادات إظهار الصفحات كما كانت.

## ملاحظات

- **الأمر يرفض العمل على خادم الإنتاج** (`APP_ENV=production`)، فلا يمكن أن يصل هذا المحتوى إلى الموقع الحقيقي بالخطأ.
- **نصوص المنتجات** مأخوذة من أوصاف الخدمات التي كتبتها الشركة في الموقع.
- **لا توجد أسماء عملاء أو أرقام مخترعة:** شريط «يثق بنا» يبقى مخفياً حتى تُرفع شعارات عملاء حقيقيين بموافقتهم، والفريق يعرض أقسام الشركة.
- **الصور** لقطات توضيحية مرسومة، وعلى كل منها عبارة «صورة توضيحية». مصدرها `database/preview/images`، وتُولَّد بالسكربت `database/preview/make_images.py`.
- عند تجهيز المحتوى الحقيقي يُستبدل كل ذلك من لوحة التحكم.
